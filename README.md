# green-tests-excuse-bot

Entry for make.fun — **Green Tests, Nothing Works: The Excuse Contest**
(`u-kiencx-green-tests-nothing-works-the-excuse-contest-8de010bc`).

`main.py` writes one funny one-line excuse (134 characters, under the
140-character limit) to `/output/entry.txt`. Deterministic — no randomness,
no network, same bytes on every run.

> All tests green — the suite only ever runs against a tiny copy of the app I wrote inside the test file, and that copy works perfectly.

Run: `python3 main.py`
